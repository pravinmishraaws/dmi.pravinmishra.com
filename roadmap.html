Start in the right place

The DMI track is the spine — 14 weeks, graded, in order. Pick where you join it, then follow the path below. Each stage also shows the Udemy course that covers the same ground, and what you can learn free on YouTube.

The DMI Track

All 14 weeks, in order

This is the real curriculum — every week is assignments you submit and that get graded. Gold tags are the Udemy course covering that ground if you would rather take it standalone.

1
Weeks 00–02

Get oriented

How the internet and networking actually work, the working habits the rest of the track assumes, and using agentic AI as a daily engineering tool rather than a novelty.

Internet & Networking Success Mindset Agentic AI Udemy: Agentic AI DevOps ↗
2
Weeks 03–05

Engineering basics

Linux and bash until the terminal stops being scary, Git and GitHub the way teams actually use them, and the DevOps lifecycle that ties planning to delivery.

Linux & Bash Git & GitHub DevOps Lifecycle Udemy: Linux for DevOps ↗
3
Weeks 06–07

Cloud platforms

AWS first and properly — accounts, budgets, core services — then Azure, so you are not locked to one provider when you start applying for jobs.

AWS Cloud Azure Cloud Udemy: AWS Fundamentals ↗ Udemy: CLF-C02 cert prep ↗
4
Weeks 08–10

Automate the infrastructure

Stop clicking in consoles. Terraform for provisioning, Ansible for configuration, and Azure DevOps pipelines to run it all without you watching.

Terraform Ansible Azure DevOps Udemy: AWS CI/CD & CodePipeline ↗
5
Weeks 11–12

Containers and orchestration

Docker from a first container to a real deployment, then Kubernetes — pods, services and the operational reality of running them.

Docker Kubernetes Udemy: Docker, K8s & CI/CD ↗ Udemy: EKS, ArgoCD & Helm ↗
6
Week 13

Ship the final project

Put the whole stack together into one deployed, reviewable project — the thing you actually show a hiring manager, and what your badge page links to.

Final Project Portfolio Udemy: 5 Real-World Projects ↗

Same material, three different levels of commitment and support.
