## About the Program

A hands-on, mentor-led **14-week program** combining DevOps and Agentic AI. Students deploy real apps, build CI/CD pipelines, automate infrastructure, and ship a capstone project powered by AI.

**Cohort 3 starts June 6, 2026** — applications open via the website.

## Data Files

### `data/leaderboard.csv`
**Auto-generated** by `dmi-review-agent`'s `publish` step (auto-merged PR on every graded run) — not normally hand-edited. CSV with columns: `Name, Group, Github, Total`
- `Github` is the student's bare username; the page links their "DMI GitHub Portfolio" to `github.com/<Github>/devops-micro-internship-pravinmishra` (their actual assignment repo, not their profile)
- Total is the overall score

### `data/self-paced-leaderboard.csv` / `data/self-paced-graduates.json`
Same auto-generated pattern, for the Self-Paced track. In-progress students: `Name, GithubUsername, SectionsCompleted, Total`. Students who complete all 14 sections are moved into the graduates JSON automatically: `{name, github_username, country, role, linkedin, photo, total, sections_completed}`.

If either of these files' column/field names ever need to change, `leaderboard.html`/`self-paced-leaderboard.html`'s JS must be updated in the same change — see `CLAUDE.md`.

### `data/champion.json`
JSON with `current_week`, `cohort`, and a `weeks` array. Each week lists one champion per group with name, score, mentor comment, LinkedIn, and optional photo.

### `data/cohort1.json` / `data/cohort2.json`
JSON arrays of graduate objects: `name`, `country`, `role`, `linkedin`, `photo`, `group`.

## Deployment

This site is hosted on **AWS S3 + CloudFront** as a static site.

See [HOW-TO-UPDATE.md](HOW-TO-UPDATE.md) for:
- First-time deployment (S3, CloudFront, Route 53)
- Day-to-day content updates with cache invalidation commands
- A quick reference table for each data file

**Quick deploy (all files):**
```bash
aws s3 sync . s3://dmi.pravinmishra.com \
  --exclude ".claude/*" \
  --exclude "*.md" \
  --exclude ".DS_Store"

aws cloudfront create-invalidation \
  --distribution-id YOUR_DISTRIBUTION_ID \
  --paths "/*"
```
